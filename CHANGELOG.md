# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/);
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

## [1.1.0] — не выпущено

### Добавлено

- **Решения и пункты к выполнению в резюме.** Структурированное резюме теперь выделяет
  отдельными разделами «Принятые решения» (решение + обоснование) и «Пункты к выполнению» в
  формате планирования: задача, ответственный и оценка трудозатрат. Для материалов без
  совещательной части (лекция, монолог) разделы пустые и не отображаются. Заголовки
  локализованы (RU/EN); оценка трудозатрат — экспертная прикидка модели, а не цитата из
  транскрипта.

### Исправлено

- **TD-6: заголовок резюме мог быть на языке источника.** Инструкция `title` в промпте усилена —
  заголовок всегда пишется на целевом языке резюме, даже если запись звучит на другом языке
  (закрепляется и в описании поля схемы). Ждёт платной live-перепроверки на кросс-языковом входе.

## [1.0.1] — 2026-06-25

Патч: две доработки консоли по итогам первых прогонов.

### Исправлено

- **Полоса прогресса при конвертации в MP3.** Извлечение дорожки из видео шло «вслепую» —
  одна строка и зависшая консоль до конца работы ffmpeg. Теперь конвертация показывает ту же
  полосу `%/ETA`, что и транскрипция: длительность определяется заранее, а прогресс считывается
  из ffmpeg на лету.
- **Папка результата открывается в Explorer для всех сценариев.** Раньше папка всплывала только
  после сохранения транскрипта. Теперь один раз за запуск открывается нужная папка по выбору в
  меню: `output/audio` после «MP3 only», `output/transcripts` после транскрипции. Окно открывается
  **в фоне**, не перехватывая фокус у консоли (`ShellExecuteW` + `SW_SHOWNOACTIVATE`).

## [1.0.0] — 2026-06-23

Первый релиз. EchoGist — консольный инструмент для Windows, запускаемый одним файлом:
берёт локальный аудио/видео файл (или сохранённый транскрипт) и выдаёт MP3-дорожку и/или
структурированное RU/EN резюме. Транскрипция — локально на GPU; резюме — один облачный
вызов Anthropic. Без логинов, онлайн-источников и истории.

### Возможности

- **Извлечение MP3** из локального видео/аудио (`imageio-ffmpeg`, без ручной установки ffmpeg).
- **Локальная GPU-транскрипция** через faster-whisper `large-v3` (`int8_float16`):
  авто-определение RU/EN, тайм-коды по сегментам, сохранение полного транскрипта.
- **Структурированное резюме** одним вызовом: о чём, ключевые выводы, тайм-коды по смысловым
  блокам, повторяющиеся темы, главная идея. Вывод в **PDF** (шрифт DejaVu, кириллица без «тофу»)
  или **Markdown**, на русском или английском.
- **Восстановление из транскрипта**: если облачный вызов сорвался (нет сети/ключа), транскрипт
  уже сохранён — резюме перегоняется без повторной транскрипции.
- **Контроль расходов**: локальная (офлайн) языко-зависимая оценка стоимости и подтверждение
  выше порога ($0.50 по умолчанию) до оплачиваемого вызова; фактическая стоимость — после.
- **Один `run.bat`**: идемпотентный первый запуск — venv, хеш-пиннутые зависимости, разовая
  загрузка модели, GPU-префлайт с понятной диагностикой.
- **Современная консоль** (questionary + rich): меню со стрелками, таблица настроек, полоса
  прогресса `%/ETA`, нативный выбор файла, навигация `← Back`, скрытый быстрый выбор 1–9,
  всплытие папки в Explorer после сохранения, панели результата/ошибки.
- **Настройки**: язык резюме, формат вывода, тариф модели (economy/balanced/flagship), порог
  стоимости — данные в конфиге, правятся без изменения кода.

### Архитектура и безопасность

- **Killswitch**: сетевой только этап `SUMMARIZE`; всё слева от него (включая оценку токенов и
  стоимости) — локально и офлайн, тестируется в CI против стаб-суммаризатора.
- **Чистые стадии** и **восстановление на артефактах** (сохранённый транскрипт = чекпоинт):
  ни `job.json`, ни слоя истории.
- **Ключ Anthropic** — только из `ANTHROPIC_API_KEY` или локального `config/secrets.toml`;
  никогда в коде и не коммитится.
- Гейт на каждый push в `main`: ruff + mypy --strict + тесты.
