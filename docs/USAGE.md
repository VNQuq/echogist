# Как пользоваться EchoGist

Короткий гайд: от «только что скачал» до «получил резюме». EchoGist берёт локальный
аудио/видео файл (или сохранённый транскрипт) и делает MP3-дорожку и/или структурированное
резюме (PDF или Markdown). Транскрипция — локально на GPU, резюме — один вызов облачного
Anthropic API.

## Что нужно до первого запуска

- **Windows** + **Python 3.11.x** в PATH (именно 3.11 — `run.bat` другие версии не примет).
- **ffmpeg** в PATH (или рядом с приложением) — им читаются видео и звук.
- **GPU NVIDIA** с CUDA — на нём работает Whisper.
- **Ключ Anthropic** — нужен только для резюме. Задаётся одним из двух способов:
  - переменная окружения `ANTHROPIC_API_KEY`, **или**
  - файл `config/secrets.toml` (скопируй `config/secrets.toml.example`, впиши ключ в
    `anthropic_api_key`).

  Без ключа извлечение MP3 и транскрипция всё равно работают — резюме просто не запустится.

## Первый запуск

Запускается одним файлом:

```bat
run.bat
```

При первом запуске `run.bat` сам всё подготовит: проверит Python, создаст виртуальное
окружение, поставит зависимости, создаст папки `output/`, **один раз скачает модель Whisper**
(несколько ГБ с Hugging Face) и проверит GPU. Это занимает время и требует интернета —
дальше модель берётся локально и запуск идёт сразу к меню.

> Если окно закрылось с ошибкой — прочитай сообщение над строкой `Startup aborted`, там
> написано, что починить. Окно ждёт нажатия клавиши, не пропадает мгновенно.

## Главное меню

После запуска появляется меню. Двигайся **стрелками ↑/↓**, выбирай **Enter**.

![Главное меню](images/menu-main.png)

- **1. Local file (audio/video)** — взять локальный файл.
- **2. Saved transcript** — пере-резюмировать ранее сохранённый транскрипт.
- **3. Settings** — язык резюме, формат, модель, порог стоимости.
- **4. Exit** — выход.

В подменю есть пункт **← Back**, чтобы вернуться на шаг назад. **ESC и Ctrl-C выходят из
приложения целиком** (а не «назад») — для возврата используй именно `← Back`.

## Сценарий 1: видео/аудио → MP3 и/или резюме

Выбери **Local file**. Откроется системное окно выбора файла (в первый раз — на папке
`Загрузки`, потом запоминает последнюю).

![Выбор файла](images/pick-file.png)

Дальше EchoGist спросит, что сделать:

- **Summary** — резюме (транскрипция + один облачный вызов).
- **MP3 only** — только вытащить дорожку в MP3.
- **Both (MP3 + summary)** — и то, и другое.

Если выбранный файл **уже MP3**, конвертировать нечего — предложат только **Summary** или
**Transcript only** (остановиться на сохранённом транскрипте без облачного вызова).

При транскрипции показывается полоса с процентом и оставшимся временем:

![Прогресс транскрипции](images/progress.png)

Перед оплачиваемым вызовом EchoGist показывает **оценку стоимости**. Если она дороже порога
(по умолчанию $0.50), спросит подтверждение y/n; если дешевле — идёт сразу. После ответа
модели показывается фактическая стоимость и путь к готовому файлу.

## Сценарий 2: готовый транскрипт → резюме

Выбери **Saved transcript** — это путь восстановления. Если резюме когда-то не удалось
(пропал интернет, не было ключа), транскрипт уже сохранён, и его можно пере-резюмировать
**без повторной транскрипции**. Выбери файл из списка `output/transcripts/` стрелками или
впиши путь вручную.

## Где лежат результаты

```
output/
├── audio/            # извлечённые MP3
├── transcripts/      # полные транскрипты (.txt) — это и есть «чекпоинт»
└── summaries/        # готовые резюме (.pdf / .md)
    └── raw/          # сырой .json резюме (для повторного рендера без оплаты)
```

## Настройки

Меню **Settings** меняет четыре параметра и сохраняет их в `config/settings.json`:

![Меню настроек](images/settings.png)

- **Summary language** — язык резюме: `ru` или `en` (по умолчанию `ru`).
- **Output format** — `pdf` или `md` (по умолчанию `pdf`).
- **Model tier** — какая модель резюмирует (по умолчанию `economy`):

  | Tier | Модель | Контекст | Цена (вход / выход за 1М токенов) |
  |------|--------|----------|-----------------------------------|
  | `economy` | Haiku | 200K | $1 / $5 |
  | `balanced` | Sonnet | 1M | $3 / $15 |
  | `flagship` | Opus | 1M | $5 / $25 |

- **Cost confirm threshold** — выше этой суммы EchoGist спрашивает подтверждение перед
  оплачиваемым вызовом (по умолчанию $0.50).

> Модели, цены и текст промпта — это данные, а не код: их можно править прямо в
> `config/models.toml` без изменения программы.

## Если что-то пошло не так

EchoGist никогда не падает молча: при любой ошибке он печатает понятное сообщение и
возвращает в меню. Самое частое:

- **«No Anthropic API key found» (F3).** Ключ не задан. Поставь `ANTHROPIC_API_KEY` или
  заполни `config/secrets.toml` и перезапусти. Транскрипт уже сохранён — просто
  пере-резюмируй его из пункта **2**.
- **«This transcript is too long…» (F6).** Текст не влезает в один проход на текущей модели.
  Открой **Settings** и выбери модель с большим контекстом (`balanced` или `flagship`).
  Транскрипт сохранён, оплаты не было.
- **«Model not found… fetching from Hugging Face» висит или падает.** Нет связи с Hugging
  Face (бывает нужен VPN). Дождись интернета и перезапусти `run.bat`, либо положи файлы
  модели вручную в `models/large-v3-int8_float16/` (`model.bin`, `config.json`,
  `tokenizer.json`, `vocabulary.*`, `preprocessor_config.json`).
- **«Python is not on PATH» / «needs Python 3.11.x».** Поставь Python 3.11 с
  python.org и перезапусти.
- **Не находит ffmpeg.** Добавь ffmpeg в PATH или положи рядом с приложением.
