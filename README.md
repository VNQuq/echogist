# EchoGist

> Достаёт суть из видео и аудио — извлекает дорожку или делает структурированное резюме.

```text

 |  __| / __| '_ \ / _ \ | |_ | / __| __|
 | |___| (__| | | | (_) | |__| | \__ \ |_
 |______\___|_| |_|\___/ \_____|_|___/\__|
```

**EchoGist** — консольное приложение для Windows, запускаемое одним файлом. На вход
принимает локальный аудио/видео файл (или ранее сохранённый транскрипт) и по выбору
извлекает MP3-дорожку и/или формирует резюме содержания (о чём, ключевые выводы,
повторяющиеся факты, главная идея) с тайм-кодами по крупным смысловым блокам.
Полностью офлайн на этапе транскрипции (локальный GPU Whisper); резюмирование — через
облачный Anthropic API. Без логинов и онлайн-источников.

## Возможности

- 🎧 Извлечение и сохранение аудиодорожки (MP3) из локального видео.
- 📝 Структурированное резюме видео/аудио через Anthropic API.
- 📁 Источники: основные локальные аудио/видео форматы и сохранённые транскрипты.
- 🗣️ Локальная транскрипция из звука (работает даже без субтитров), RU и EN.
- 🎛️ Интерактивное красочное меню с выбором действия на каждом запуске.
- ⚙️ Настройки: язык резюме, формат вывода (PDF / Markdown), выбор модели.
- 💰 Предупреждение и расчёт примерной стоимости перед каждым резюмированием.

## Запуск

```bat
run.bat
```

При первом запуске батник сам подготовит окружение и установит зависимости,
далее — просто запускает приложение.

📖 Подробный гайд по использованию: [docs/USAGE.md](docs/USAGE.md).
📋 История изменений: [CHANGELOG.md](CHANGELOG.md).

## Требования

- Windows + Python (в PATH).
- ffmpeg ставить не нужно — он идёт в комплекте (`imageio-ffmpeg`).
- Переменная окружения `ANTHROPIC_API_KEY` для резюмирования.

## Структура вывода

```
output/
├── audio/         # извлечённые MP3
├── transcripts/   # полные транскрипты
└── summaries/     # итоговые документы-резюме (PDF / MD)
```

## Сценарии

| Вход | Доступные действия |
|------|--------------------|
| Локальный видеофайл | только MP3 · только резюме · оба |
| Локальный аудиофайл | резюме · (опц.) конвертация в MP3, если ещё не MP3 |
| Сохранённый транскрипт | только резюме (без повторной транскрипции) |
