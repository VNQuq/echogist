# EchoGist

> Достаёт суть из видео и аудио: извлекает дорожку или делает структурированное резюме.

```text
  ______     _           _____ _     _
 |  ____|   | |         / ____(_)   | |
 | |__   ___| |__   ___| |  __ _ ___| |_
 |  __| / __| '_ \ / _ \ | |_ | / __| __|
 | |___| (__| | | | (_) | |__| | \__ \ |_
 |______\___|_| |_|\___/ \_____|_|___/\__|
```

**EchoGist** — консольное приложение для Windows, запускаемое одним файлом. Вход — локальный
аудио/видео файл или сохранённый транскрипт. Выход — MP3-дорожка и/или **структурированное
резюме**: связная проза по ходу записи, блок сути (главная мысль, главный навык и три
проверочных вопроса с ответами), сквозные темы и (если были) решения и пункты к выполнению, с
тайм-кодами внутри текста.

Транскрипция — локально на GPU (Whisper). Резюмирование — в облаке Anthropic: по вызову на
каждую фазу записи и один сводящий. Без логинов, онлайн-источников и истории.

## Возможности

- **MP3** — извлечение и сохранение аудиодорожки из видео.
- **Резюме** — проза с тайм-кодами через Anthropic API, RU или EN.
- **Локальная транскрипция** — GPU Whisper, работает без субтитров.
- **Папка целиком** — все записи одной папки: MP3, транскрипты или резюме, с одним
  подтверждением цены на весь прогон и отчётом по папке до него.
- **Восстановление** — сохранённый транскрипт = чекпоинт для повторного резюме без транскрипции.
- **Контроль расходов** — офлайн-оценка стоимости и порог подтверждения перед вызовом.
- **Проверки над готовым резюме** — каждый тайм-код сверяется с реальной записью; фаза,
  вернувшаяся пустой, роняет файл, а не уезжает молча, и в конце прогона EchoGist
  предлагает повторить только её; пустой заголовок или пункт сути и документ, написанный
  не на том языке, называются вслух.
- **Настройки** — язык, формат (PDF / Markdown), тариф модели, порог подтверждения цены,
  число потоков MP3 в папочном прогоне; данные в конфиге.

## Быстрый старт

```bat
run.bat
```

Первый запуск сам готовит окружение, ставит зависимости и разово качает модель. Дальше — сразу
в меню.

## Требования

| Требование | Примечание |
|---|---|
| Windows + **Python 3.11.x** в PATH | строго `3.11.` |
| GPU NVIDIA + CUDA | локальный Whisper |
| Ключ Anthropic | только для резюме (`ANTHROPIC_API_KEY` или `config/secrets.toml`) |

ffmpeg в комплекте (`imageio-ffmpeg`) — ставить не нужно.

## Сценарии

| Вход | Действия |
|---|---|
| Видеофайл или аудио не в MP3 (`.wav`, `.m4a`, `.flac`…) | MP3 only · Summary · Transcript (MP3 сохраняется всегда) |
| Аудиофайл `.mp3` | Summary · Transcript only · пережать в MP3 поменьше |
| Сохранённый транскрипт | резюме без повторной транскрипции |
| Папка | те же действия сразу для всех файлов внутри, включая подпапки |

## Структура вывода

```text
output/
├── audio/         # извлечённые MP3
├── transcripts/   # полные транскрипты
├── logs/          # по файлу на запуск — стенограмма консоли
└── summaries/     # резюме (PDF / MD)
    └── raw/       # сырой .json — повторный рендер без оплаты
        └── .resume/   # фазы, дошедшие до конца перед сбоем
```

Папки плоские: группировка живёт в ИМЕНИ файла, а не в подкаталогах. Резюме называется
`<дата>-<имя записи>-<заголовок>.pdf`, транскрипт — `<дата>-<имя записи>-<отпечаток>.txt`.
Поэтому сортировка по имени сама раскладывает файлы по прогонам, а внутри прогона — по
занятиям, и два прохода по одному курсу видно как два блока. Дата у резюме — дата ПРОГОНА,
одна на всю папку: прогон на 18 часов иначе разъехался бы через полночь на две даты.
