# EchoGist

> Достаёт суть из видео и аудио — извлекает дорожку или делает структурированное резюме.

```text
  ______     _           _____ _     _
 |  ____|   | |         / ____(_)   | |
 | |__   ___| |__   ___| |  __ _ ___| |_
 |  __| / __| '_ \ / _ \ | |_ | / __| __|
 | |___| (__| | | | (_) | |__| | \__ \ |_
 |______\___|_| |_|\___/ \_____|_|___/\__|
```

**EchoGist** — консольное приложение для Windows, запускаемое одним файлом. На вход
принимает ссылку (YouTube / Vimeo) или локальный аудио/видео файл и по выбору
извлекает MP3-дорожку и/или формирует резюме содержания (о чём, ключевые выводы,
повторяющиеся факты, главная идея) с тайм-кодами по крупным смысловым блокам.

## Возможности

- 🎧 Извлечение и сохранение аудиодорожки (MP3) из ссылки.
- 📝 Структурированное резюме видео/аудио через Anthropic API.
- 🌐 Источники: YouTube, Vimeo и основные локальные аудио/видео форматы.
- 🗣️ Транскрипция из звука (работает даже без субтитров), RU и EN.
- 🎛️ Интерактивное красочное меню с выбором действия на каждом запуске.
- ⚙️ Настройки: язык резюме, формат вывода (PDF / Markdown), выбор модели.
- 💰 Предупреждение и расчёт примерной стоимости для длинных видео (2 ч+).

## Запуск

```bat
run.bat
```

При первом запуске батник сам подготовит окружение и установит зависимости,
далее — просто запускает приложение.

## Требования

- Windows + Python (в PATH).
- ffmpeg (в PATH или рядом с приложением).
- Переменная окружения `ANTHROPIC_API_KEY` для резюмирования.

## Структура вывода

```
output/
├── audio/         # извлечённые MP3
├── transcripts/   # полные транскрипты
└── summaries/     # итоговые документы-резюме (PDF / MD)
```

## Сценарии

| Вход | Доступные действия |
|------|--------------------|
| Ссылка (YouTube / Vimeo) | только MP3 · только резюме · оба |
| Локальный файл | только резюме |
