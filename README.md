# EchoGist

> Достаёт суть из видео и аудио: извлекает дорожку или делает структурированное резюме.

```text

 | |___| (__| | | | (_) | |__| | \__ \ |_
 |______\___|_| |_|\___/ \_____|_|___/\__|
```

**EchoGist** — консольное приложение для Windows, запускаемое одним файлом. Вход — локальный
аудио/видео файл или сохранённый транскрипт. Выход — MP3-дорожка и/или **структурированное
резюме**: связная проза по ходу записи, главная идея, сквозные темы и (если были) решения и
пункты к выполнению, с тайм-кодами внутри текста.

Транскрипция — локально на GPU (Whisper). Резюмирование — один облачный вызов Anthropic. Без
логинов, онлайн-источников и истории.

## Возможности

- **MP3** — извлечение и сохранение аудиодорожки из видео.
- **Резюме** — проза с тайм-кодами через Anthropic API, RU или EN.
- **Локальная транскрипция** — GPU Whisper, работает без субтитров.
- **Папка целиком** — все записи одной папки: MP3, транскрипты или резюме, с одним
  подтверждением цены на весь прогон и отчётом по папке до него.
- **Восстановление** — сохранённый транскрипт = чекпоинт для повторного резюме без транскрипции.
- **Контроль расходов** — офлайн-оценка стоимости и порог подтверждения перед вызовом.
- **Настройки** — язык, формат (PDF / Markdown), тариф модели; данные в конфиге.

## Быстрый старт

```bat
run.bat
```

Первый запуск сам готовит окружение, ставит зависимости и разово качает модель. Дальше — сразу
в меню.

## Требования

| Требование | Примечание |
|---|---|
| Windows + **Python 3.11.x** в PATH | строго `3.11.` |
| GPU NVIDIA + CUDA | локальный Whisper |
| Ключ Anthropic | только для резюме (`ANTHROPIC_API_KEY` или `config/secrets.toml`) |

ffmpeg в комплекте (`imageio-ffmpeg`) — ставить не нужно.

## Сценарии

| Вход | Действия |
|---|---|
| Видеофайл | MP3 only · Summary · Transcript (MP3 сохраняется всегда) |
| Аудиофайл (`.mp3`) | Summary · Transcript only |
| Сохранённый транскрипт | резюме без повторной транскрипции |
| Папка | те же действия сразу для всех файлов внутри, включая подпапки |

## Структура вывода

```text
output/
├── audio/         # извлечённые MP3
├── transcripts/   # полные транскрипты
├── logs/          # по файлу на запуск — стенограмма консоли
└── summaries/     # резюме (PDF / MD)
    └── raw/       # сырой .json — повторный рендер без оплаты
        └── .resume/   # фазы, дошедшие до конца перед сбоем
```
